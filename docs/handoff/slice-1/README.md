## 字体实测（2026-10-24 00:12–00:16）

- 常浩同意后从 GitHub `lxgw/LxgwWenKai` v1.530 下载 Regular 与 Medium（该版本没有 Bold，粗体用 Medium 顶替）；来源哈希与子集哈希见 `miniapp/fonts/README.md`。
- 子集（GB2312 + ASCII + 标点 + 界面符号，7031 码位，WOFF）：Regular 2,106,132 B，Medium 2,114,520 B，都在 4 MB 门槛内。
