# V6 拙趣手写｜组件规范

版本：`v6-authority-v1`。2026-10-23，Claude 依据常浩用 GPT 生成的画面整理。

状态不写在这里，以 `manifest.json` 的 `status` 和项目根目录 `HANDOFF.md` 的批准记录为准。常浩批准清单哈希之前，本目录的一切都只是 reference_only。

## 0. 这份规范管什么

权威包由以下几部分组成，清单和哈希见 `manifest.json`：

| 成员 | 文件 | 说明 |
|---|---|---|
| 标准屏 | `derived/screen-1-home.fixed.png` | 本月首页。原图 `gpt-assets/screen-1-home.png` 按 G2、G5 机械修正 |
| 组件板 | `derived/sheet-components.fixed.png` | 原组件板按 G4 机械修正，视频时长标签改成深色，占位字改成 ink-2 |
| 组件板·补充 | `derived/sheet-components-supplement.png` | 从 GPT 屏按组件裁切的 15 块，补齐原组件板没有的状态 |
| token | `tokens.json` | 颜色、字、间距、圆角、尺寸、线条 |
| 组件规范 | 本文件 | 规则、状态、内容预算、素材登记 |
| 登记素材 | `assets.json` 及其列出的文件 | 插画、手写标题、笔触、状态记号、圆按钮 |
| 参考屏 | `gpt-assets/screen-2` 至 `screen-16` | 其他页面和状态的样子；与本规范冲突处以本规范为准（第 7 节列出） |

**冲突时的优先顺序**：本规范 ＞ token ＞ 标准屏、组件板（修正版）＞ 组件板·补充 ＞ 参考屏。

所有派生都是用 GPT 原图里已有的像素机械处理（覆盖、正片叠底、裁切、去白底、换色相、按墨量换色），没有手画，也没有重新生成。每一步的源哈希、操作和结果哈希在 `derived/fix-log.json`、`derived/compose-log.json`、`assets.json`，可用 `tools/` 里的脚本重做（第 9 节）。

**画面里的字**：GPT 图里的字都是画出来的。实现时，会变的字（名字、日期、条目、数字、说明）一律用霞鹜文楷显示，只有固定的手写标题用素材图。所以实现后的字形会和图不同，这是已确认的取舍（10-23 常浩：「你不用管字体」，句子与条目用霞鹜文楷，名字用同一字体大号显示）。

## 1. 尺寸怎么换算

- 单位是 pt，按 390 宽手机。GPT 屏里手机外框内宽 832px，对应 390pt，1px ≈ 0.469pt。
- 外框高 1502px ≈ 704pt，比 390×844 的整屏矮。约定：**外框顶 = 自定义导航栏（微信胶囊那一行）的下沿，外框底 = 底部安全区的上沿**。状态栏和胶囊那一行只铺纸色，不放内容。这样右上角的插画不会压到胶囊。
- 量测证据：`evidence/measure-screen-1.png`。所有数值都在 `tokens.json` 里附了量到的原值。

## 2. 颜色

只有一种纸、一种墨，加两种点缀：淡蓝、浅绿。具体色值见 `tokens.json`。

| token | 色值 | 只用于 |
|---|---|---|
| paper | #FCFCFC | 页面和弹层的底 |
| ink | #111111 | 正文、标题、状态记号、输入线、圈叹号 |
| ink-2 | #707070 | 小字、日期、未选中的底栏和选项、「取消」「收起」、输入框占位字 |
| photo-placeholder | #F2F2F2 | 照片还没加载出来时的占位块（选定值，非量测） |
| blue | #B3CBE0 | 选中的字下一笔；进行中状态前的小点；底栏当前页小点 |
| green | #CFDD97 | 进度条填充 |
| highlight | #E0EAB8 | 主动作下的一笔浅绿；「记一笔」圆按钮底 |
| green-mark | #BDD472 | 照片格右上角的精选小点 |
| scrim | 黑 50% | 弹层背后的遮罩 |
| grabber | #B5B5B5 | 弹层拖动条 |
| video-tag | 黑 60%，字白色 | 照片上的视频时长标签 |

规则：

- **不用红色**，也不用淡蓝、浅绿以外的强调色。提醒、出错、医生提示都用黑色记号加文字表达（G3）。
- 纸面不用纹理图。GPT 图里的纸纹量过：亮度标准差 1.3，模糊 6px 后只剩 0.5，看不出来，所以只用纯色。
- 插画里可以有自然的颜色（土的棕色、皮肤、垫子的绿），但只在插画里，不进界面元素（G6）。
- 不用卡片、边框、阴影；靠留白分组。
- 组件板上的色点是水彩示意，色值以本表为准（例如灰色点比 ink-2 浅，白色点比纸色暖）。

## 3. 字

全站只用霞鹜文楷，三级字，另有名字和测量数字两个特例。

| 级别 | 字号 / 行高 | 字重 | 用在哪 |
|---|---|---|---|
| title | 28 / 1.3 | Bold | 区块标题、月龄（3 个月 2 天） |
| item | 20 / 1.5 | Regular | 条目、动作、首页那句话、底栏、输入内容 |
| small | 14 / 1.5 | Regular | 日期、说明、来源、标题旁小注、单位 |
| display-name | 72 / 1.1 | Bold | 首页宝宝名字 |
| number | 44 / 1.1 | Regular | 测量数字 |
| 手写标题 | 素材图，墨迹高 56 | — | 这个月、长大了、相册、记一笔、上个月 |

内容预算：

- **名字**：2 个字用 72；3 个字及以上降到 56；仍放不下就换行，最多两行。名字右边不能碰插画，插画让到名字下方。
- **条目**：一行为主，最多两行，超出省略。右侧状态或动作不换行，左侧条目让位。
- **小字**：一行，超出省略。
- **区块标题**：一行；右边的小注放不下就移到下一行。

## 4. 间距与版式

| 用途 | 值（pt） |
|---|---|
| 页面左右边距 | 24 |
| 区块之间 | 40 |
| 区块标题到第一条 | 16 |
| 条目到它下面的小字 | 4 |
| 可点的行最小高度 | 44 |
| 状态记号列宽 / 记号到字 | 18 / 14 |
| 底栏高度 | 56，另加底部安全区 |
| 照片间距 | 8 |

版式规则：

- 每屏最多一张插画，放在标题右侧或右上，面积不超过屏幕的 1/5；插画不带数字和数据。
- 每屏只有一处主动作（一笔浅绿）。
- 右侧对齐的状态和动作，右边界与页面右边距对齐。

## 5. 组件

触控区一律不小于 44×44pt，视觉上的字小不代表能点的范围小。

### 5.1 状态记号（G2、G12、G3）

| 状态 | 记号 | 素材 |
|---|---|---|
| 要安排 | 空心圈 | `mark-todo` |
| 办完了 / 看到了 | 勾 | `mark-done` |
| 还没看到 | 虚线圈 | `mark-not-yet` |
| 没记过 | 短横 | `mark-none` |
| 医生提示要留意 | 叹号 | `mark-doctor` |

- 记号**一律纯黑**，不填色、不加底色、不用淡蓝或浅绿（G2、G12），叹号也是黑色（G3）。
- 「已约」「正在留意」这类**进行中**状态，在状态字前面放一个淡蓝小点（8pt），记号本身仍是空心圈。小点只放在状态字前面，不放进圈里。常浩 10-23 确认：「淡蓝小点表示进行中的状态，『已约』和『正在留意』都用。」
- 「没有记录」「家里尚未观察到」「医生提示需要关注」分开显示：分别用短横、虚线圈、叹号，配各自的字，不合并。
- 补充板第 12、13 块是样子。

### 5.2 选中（G4）

- 选中的字下面一笔淡蓝（`marks-highlight` 上排的笔触），高 6，离字 4，两端略伸出。**不用左侧竖条**。
- 未选中的选项用 ink-2。
- 用在：二选一（看到了 / 留意了，还没看到）、记一笔的类型、测量地点、底栏之外的所有单选。
- 底栏当前页不用下划线，用字下方 6pt 处的淡蓝小点，当前页字色 ink，其余 ink-2。
- 补充板第 2、3、5、7 块。

### 5.3 动作

- **主动作**：字下面一笔浅绿（`marks-highlight` 下排的笔触），高 16，压在字的下半部，两端伸出约 8。每屏只一处。
- **次要动作**：「定个日期 →」「看看 →」「改 →」这种字加箭头，item 字号，没有底色。
- 主动作放在内容末尾的右侧；弹层里在右下角。
- 不做实心按钮、不做描边按钮。

### 5.4 底栏

四个等宽的格：本月、阶段、成长、相册。item 字号；当前页 ink 加下方淡蓝小点，其余 ink-2。高 56，另加底部安全区。没有分隔线和底色。

### 5.5 「记一笔」圆按钮

- 素材 `fab-add`（浅绿底、黑线圈、加号），显示直径 56；下方「记一笔」三个字用 item 字号。
- 在本月页右下，距右边 24，在底栏上方。只在本月页出现。
- 它就是本月页的主动作，所以本月页其他地方不再用浅绿高光。

### 5.6 弹层

- 从底部升起，顶部圆角 20，纸色底；背后整页盖黑 50% 遮罩。
- 顶部居中拖动条 32×3，颜色 grabber。
- 标题用手写标题素材或 title 字号；右上「取消」或「收起」，ink-2。
- 记一笔的五个类型：图标（`icon-*`，36pt）在上，名字（item）在下，五格等宽；选中的名字黑色加淡蓝下划一笔，其余 ink-2。
- 主动作在右下角；次要动作「先放着」在左下。
- 键盘弹出时，主动作移到键盘正上方，不被挡住（补充板第 4 块）。
- 补充板第 1、6、9、10 块。

### 5.7 输入

- 只有一条下划线，ink、1.5 粗，没有框。
- 占位字用 ink-2，以「比如：」开头和输入内容区分；输入内容 item、ink。图里的占位字比 ink-2 浅，以本条为准：那种浅灰在纸色上对比度只有 3.4:1。
- 光标用系统光标。
- 医生原话照记时，前后加「」。
- 补充板第 4、7 块。

### 5.8 测量

- 日期一行，可「改 →」；地点二选一（家里 / 医院或社区），选中下划淡蓝。
- 身高、体重、头围各一行：左边名称，中间输入线，右边单位（small）。没量可以不填，占位字写「没量可以不填」。
- 下方小字说明「只记量到的数，不做判断」。
- 结果显示：大号数字（number）＋小号单位，下面一行小字说明（补充板第 11 块）。
- 补充板第 5 块。

### 5.9 照片格

- 3 列，间距 8，照片是正方形（1:1），圆角 6，照片之间不加边框。
- 精选：右上角一个 green-mark 小点。
- 视频：左下角时长标签「▶ 0:42」，**半透明黑底（黑 60%）、白字**，字号 small，高 16，圆角 8，左右内边距 6。黑 60% 叠在纯白照片上，白字对比度仍有 4.9:1；55% 时只有 4.2:1。常浩 10-23 决定用深色：真实照片常有白毯子，白标签容易看不清。
- 组件板上的白标签已按原图像素机械改成深色（`evidence/video-tag-compare.png`）；相册页参考屏仍是白的，以本条为准。
- 时长标签在提示词里不能写成「pill」，会被画成药片（G1）；要写「深色小标签」。
- 照片大图：上面整张照片，下面日期与备注、「设为这个月精选」（主动作）、「下载原片 →」「更多 →」、原片尺寸与大小（补充板第 8 块）。
- 批量导入：进度条高 18，黑线描边，green 填充；下面「已存好 50 / 53」；缩略图上正在存的显示虚线圈，没存上的照片变淡并在下面写「没存上」；底部「全部再试」为主动作（补充板第 9 块）。

### 5.10 空状态

- 一张插画加一句话，再加一个主动作。例：「这个月还没有照片。」＋「放照片进来 +」（组件板「空着的时候」）。
- 新的一个月：本月页换 `ill-home-leaf`，下面写「新的一个月开始了。」和一行小字（参考屏 screen-16）。
- 成长页还没有测量时，数字的位置写「还没量过」（small、ink-2），不显示 0 或假数字。
- 空状态不说「暂无数据」，也不推断原因。

### 5.11 出错（不用红色）

- 黑色圈叹号（`mark-error`）＋一句说明，说清楚出了什么事、写的东西还在不在。例：「没存上，网络好像断了。你写的都还在。」
- 次要「先放着」在左，主动作「再试一次」在右。
- 不用红色、不用弹窗打断（补充板第 10 块）。

### 5.12 二级页返回（G11）

- 二级页左上一律用小字「‹ 上一页名称」（small、ink），例：「‹ 本月」「‹ 相册」。
- 下面再放手写标题。照片大图（screen-13）左上画成了大字「相册」，以本条为准。
- 补充板第 15 块。

### 5.13 插画

- 只用于纸面背景：素材的白色部分是透明的，不能放在深色、照片或彩色底上。将来如果做深色模式，要另做一版内部填实的素材。
- 插画里不带数字、日期、名字或任何数据。
- 每屏最多一张，同一页不换图；本月页可以按情况换 sleep / leaf / rattle。
- 宝宝按安全睡姿画（仰卧、身边没有软东西），以后补画也要守住。
- 原图边缘是纯白，去白底规则见 `t1a/tools/alpha.py`。

### 5.14 手写标题

- 只用于固定的页面标题，素材图显示的墨迹高 56。
- 会变的字（名字、日期、条目）一律用字体，不用手写素材。
- 新增标题要另生成，并与已有 5 张统一粗细（G8 已接受目前的差异）。

### 5.15 加载

- 照片格：图还没加载出来时，显示同尺寸、同圆角的 photo-placeholder 纯色块；不用转圈，不用闪光动画。
- 整页数据：300ms 内不显示加载提示；超过 300ms，在内容位置显示小字「正在取…」（small、ink-2）。
- 批量导入时，正在存的那张用虚线圈（5.9）。
