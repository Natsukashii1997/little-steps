## 必须验证的边界

- 允许角色成功：自动化中普通成员可记录数据，所有者可创建备份，所有者/备用管理员可恢复。
- 越权、停用、降权或旧会话拒绝：自动化已覆盖非成员、停用成员、撤销备用管理员后的旧权限与旧版本操作；服务端拒绝且家庭数据不变。
- 无效输入与失败后恢复：日期、范围、容量、空内容、损坏备份等被拒绝；本地草稿或原家庭数据保留。
- 重复提交与并发冲突：operationId 幂等和分区合并通过；同字段冲突不静默丢弃证据。
- 写入与刷新持久化：本机 Store/微信存储替身的重载测试通过；真实 `wx` 存储在手机重开、换机和清缓存场景未验证。
- 跨页面或跨角色一致：共享 Store 和两角色内存测试通过；真实两个微信账号未验证。
- 通知成功、去重或无需通知的证据：首页 14 天内/逾期提醒与待办去重测试通过；本版本明确不做微信订阅推送。
- 回归测试：最终 `npm run verify` 通过；`Family sync merge tests: 9/9`、`Store public behavior tests: 15/15`、`Family API backup tests: 16/16`、`Family partition API tests: 10/10`、媒体保护测试 15 项通过、`CloudBase family backend structure: OK`。
