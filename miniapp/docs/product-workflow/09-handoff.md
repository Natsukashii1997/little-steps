## 第一次导入微信开发者工具

1. 在微信公众平台注册“小程序”账号，在“开发管理 → 开发设置”复制 AppID。
2. 安装最新版微信开发者工具，用小程序管理员的微信扫码登录。
3. 点“导入项目”，项目目录选择：`/Users/nat/Documents/AI 项目/baby-care-workbench/miniapp`。这是包含 `project.config.json` 的根目录，**不要选择里面的 `miniprogram` 子目录**。
4. 在导入窗口粘贴自己的 AppID。导入后在“项目详情”确认 AppID 不再是 `touristappid`。
5. 小程序图标可选项目根目录的 `小程序图标.png`。

## 第一次配置云开发

1. 在开发者工具打开“云开发”，创建一个环境，复制形如 `cloud1-xxxxxxxx` 的环境 ID。
2. 在文件树中复制 `miniprogram/config.local.example.js`，新文件命名为 `miniprogram/config.local.js`。
3. 只把下面 `envId` 的值换成自己的环境 ID，其他不改：

```js
module.exports = {
  envId: "cloud1-把这里换成你的环境ID",
  useCloud: true,
  familyMaxMembers: 6,
  schemaVersion: 4,
};
```

4. 在云数据库中逐个新建 7 个集合，名字必须完全一致：`families`、`family_snapshots`、`family_backups`、`family_manifests`、`family_partitions`、`family_operations`、`family_conflicts`。
5. 严格按 `cloudbase/README.md` 发布 `cloudbase/database.rules.json` 和 `cloudbase/storage.rules.json`。不要自己改成“所有人可读写”。
6. 在文件树右键 `cloudfunctions/familyApi`，选“上传并部署：云端安装依赖”，等待显示成功。
7. 重新点“编译”。只有 Console 和页面没有红色错误，才进入下一步。

## 用两个微信账号做真实验收

1. 账号 A 打开首页“家庭同步”，填写虚构昵称/关系并点“创建我的家庭”。
2. 看到“已连接家庭”、“当前成员 1/6”和 6 位邀请码，记为创建成功。
3. 将邀请码私下发给账号 B，账号 B 填写虚构昵称/关系后加入。
4. A/B 分别新增和修改一条虚构照护记录，点“立即同步”，确认另一台手机重开后看到相同结果。
5. 断开一台手机网络，记录一条虚构换尿布和便便，重开确认本地仍在；恢复网络后确认另一台手机能同步到。
6. 所有者指定/撤销备用管理员，并用停用成员账号尝试再访问；预期云端明确拒绝，家庭数据不变。
7. 所有者创建一份手动备份，改一条虚构记录，再用所有者/备用管理员恢复，确认记录恢复且出现恢复前保护备份。
8. 再用一张虚构照片测试备份保护：先创建包含它的备份，再从当前记录移除它；触发日常清理后，该文件仍应能从可恢复备份访问。若断网导致云端引用核对失败，本次应延后物理删除。
9. 在 iPhone 和 Android 上分别测试 Home、Memory、Growth、Health 四页及四等分底栏、原生键盘、日期选择、照片、从微信聊天选择并上传音频文件和长图保存。

## 上传家庭体验版

1. 在微信开发者工具点“上传”，版本号填 `0.1.0`，备注填“家庭体验版”。
2. 登录微信公众平台，打开“开发管理 → 版本管理”，把刚上传的开发版设为体验版。
3. 在“成员管理 → 体验成员”添加自己和家人，应用内家庭人数合计不超过 6 人。
4. 家人接受邀请后，用微信扫体验版二维码打开。
5. **不要点“提交审核”或“发布”**；本项目只使用家庭体验版。

## 数据安全与维护

- 邀请码和体验版二维码只私发给 6 位家人，不要发公开网络。
- 本地有“待同步”时，不要清微信缓存、卸载微信或销毁云环境。
- 手动云备份包含全部家庭记录和媒体引用，**不会把照片/音频文件本体重复复制到备份中**，文件本体仍在云存储。
- 删除云媒体前，小程序会通过 `getProtectedMediaReferences` 核对当前家庭数据和所有可恢复备份；若核对失败，会保留待清理文件并等待下次重试。不要为了“清空间”绕过这层保护手动批量删除云文件。
- 每月至少：点一次“立即备份”，导出一份 JSON 存档，并从云存储下载 `family-media` 中的照片和音频。JSON 当前不能在小程序一键导入。
- 免费 CloudBase 不是永久免维护；以控制台当期规则为准，提前设续期提醒，不要点“销毁环境”。
