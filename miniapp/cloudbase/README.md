## 管理员首次使用

1. 打开体验版。
2. 在首页点“个人云同步”，再点“开启个人云同步”。无需填写姓名或任何家庭信息。
3. 看到“已同步”和“记录已保存在本机和个人私密云空间”，即表示连接成功。
4. 录入一条虚构测试记录并同步，关闭后重新进入，确认记录仍然存在。
5. 再测试一张无隐私内容的图片或一段测试音频，确认本人可以重新打开。

## 数据结构说明

- `family_manifests` 保存私密工作空间的当前修订号、数据版本和分区校验信息。
- `family_partitions` 保存核心资料及按业务类型、月份划分的数据。
- `family_operations` 用于避免重复点击或重试产生重复操作。
- `family_conflicts` 保留冲突证据。
- `family_snapshots` 是旧版兼容层。
- `family_backups` 保存手动备份、自动备份和恢复前保护备份。

这些结构目前服务于管理员本人的云端同步和备份。多人权限、邀请和跨成员媒体不是本阶段上线验收项。

## 备份与安全提醒

- 管理员可在应用中创建云备份并导出离线 JSON 存档。对应云端动作是 `createBackup`、`restoreBackup` 和 `exportFamily`；这些是内部接口名，界面仍使用个人版中文文案。
- 当前小程序没有 JSON 一键导入入口；离线存档用于留存和后续人工恢复。
- 免费环境的有效期、续期和额度以云开发控制台实际显示为准。不要假定免费环境永久免维护。
- 不要点击“销毁环境”。
- 不要把 AppSecret、微信密码、验证码或云管理密钥写入项目、文档或聊天。
