# Little Steps 管理员单人体验版使用说明

这是一份只给管理员本人使用的微信小程序个人体验版。它不提交微信审核、不公开发布；当前额度足够时无需购买云开发套餐，后续如果控制台明确提示环境即将到期或容量不足，再按实际需要续费。家庭邀请、成员管理和邀请码均不出现在个人版界面中。

代码内部仍保留 `family` 技术名称以兼容数据结构，但这不影响日常使用；管理员只会看到“个人云同步”。

## 第一次打开项目

### 1. 导入正确的文件夹

1. 安装最新版[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 用小程序管理员的微信扫码登录。
3. 点“导入项目”。
4. 选择**包含 `project.config.json` 的 `Little-Steps-微信个人体验版` 文件夹**，不要选择里面的 `miniprogram` 子文件夹。
5. 在“项目详情”确认 AppID 是 `wx698361dff7730b36`，不要改成 `touristappid`。

左侧出现 `miniprogram` 和 `cloudfunctions`，中间能看到婴儿工作台首页，才表示项目导入正确。

### 2. 打开已配置的云环境

1. 在开发者工具中打开“云开发”。
2. 选择环境 `cloud1-d3gzx4mjad148a3fa`；无需创建新环境。
3. 确认能进入“数据库、云存储、云函数”。
4. 确认 7 个集合仍为“客户端不可读写”。
5. 确认云存储 bucket 存在，并保持免费档默认“仅创建者可读写”。

如果界面要求购买套餐或升级付费，先确认提示针对的是当前环境的到期、容量还是功能限制，再核对套餐、价格和有效期后决定；不要因为普通权限提示把存储改成公开。

### 3. 云函数状态

`familyApi` 已经部署到 `cloud1-d3gzx4mjad148a3fa`，状态为 `Active`；开发者工具预览编译成功，调试器 Errors 为 0。正常使用时不需要重复部署。

### 4. 开启个人云同步

1. 在首页点“个人云同步”。
2. 点“开启个人云同步”，不需要填写任何资料。
3. 看到“已同步”和“记录已保存在本机和个人私密云空间”，即表示成功。
4. 用虚构测试内容新增一条记录，等待同步；关闭小程序后重新进入，确认记录仍在。

## 生成管理员体验版

代码验证并上传新的开发版本后：

1. 登录[微信公众平台](https://mp.weixin.qq.com/)，进入“开发管理 → 版本管理”。
2. 在开发版本中找到刚上传的最新版本，核对版本号和项目备注后点“选为体验版”。
3. 管理员本人通常可直接体验；若平台仍提示没有权限，再到“成员管理 → 体验成员”只添加管理员自己的微信。
4. 用管理员微信扫描体验版二维码打开。

不要点“提交审核”，不要点“发布”，不要添加家人。本阶段只保留管理员本人使用。

第一次打开后，可以点微信右上角 `…`，选择“添加到我的小程序”；以后从微信首页下拉即可进入。小程序图标可选择交付包根目录的 `小程序图标.png`。

## 管理员手机上必须做的检查

在真正录入重要数据前，先使用虚构测试数据完成一次：

1. 依次打开 Home、Memory、Growth、Health，确认底栏只有这四项且等宽排列。
2. 新增一条记录，使用手机真实键盘修改并保存。
3. 退出再进入，确认记录仍然存在。
4. 断开网络新增一条测试记录，再恢复网络并重新同步。
5. 上传一张没有隐私内容的测试图片，退出再进入后确认还能打开。
6. 从微信文件选择器选择一段测试音频，退出再进入后确认还能打开。
7. 创建一次云备份并导出一份离线 JSON 存档。

当前小程序没有 JSON 一键导入入口；导出文件用于离线留存和后续人工恢复，不要把它当作一键恢复按钮。

如果微信提示需要配置隐私保护指引，可按平台提示声明“选中的照片或视频信息”；允许直接拍摄时再声明“摄像头”。本版本的音频通过微信文件选择器选择已有文件，不是现场录音。

## 日常使用与长期保存

- 首页“个人云同步”显示“已同步”后，记录会同时保存在本机和管理员自己的私密云空间。
- 弱网或断网时可以继续记录；恢复网络后重新打开小程序或点“立即同步”。
- 同一管理员微信换手机后，可进入体验版并重新连接原工作空间，从云端恢复数据。
- 同步失败时不要清理微信缓存或卸载微信，先恢复网络再重试。
- 每月至少创建一次云备份，并导出一份离线 JSON 存档；重要阶段（例如体检或集中补录后）立即再备份一次。
- 把导出的存档复制到手机之外的第二个位置，例如电脑或个人云盘。不要只保留在微信聊天或同一部手机中。
- 云开发环境的有效期、续期和额度以控制台实际显示为准；每月备份时顺手查看一次容量和到期提醒，绝对不要点击“销毁环境”。
- 如果出现到期或容量预警，可以付费续期或升级，但先确认购买的是环境续期/资源套餐，而不是把小程序公开发布。购买前保留控制台提示截图，避免买错服务。
- 电脑关机、手机与电脑不在同一网络，均不影响已经设为体验版的小程序和云端数据。体验版仍依赖微信平台、管理员账号和云开发环境持续有效，因此不能把“永久”理解为脱离微信平台的永久托管。

图片和音频在本阶段只承诺管理员本人访问。不要用其他微信账号测试真实数据，也不要公开体验版二维码。

## 以后更新体验版

1. 使用最新项目，不要重新使用旧 ZIP。
2. 在 `miniapp` 文件夹运行 `npm run verify`。
3. 确认 AppID、云环境和 `familyApi` 没有丢失。
4. 点“编译”，用虚构数据做一次记录、同步、图片和音频检查。
5. 点“上传”，递增版本号，例如从 `0.1.0` 改为 `0.1.1`。
6. 在微信公众平台把新开发版设为体验版。

继续保持“不付费、不提审、不公开发布、只添加管理员自己”的范围。

## 常见问题

| 现象 | 先这样处理 |
| --- | --- |
| 管理员扫码打不开 | 确认管理员微信已添加为体验成员，并已确认邀请。 |
| 首页仍显示“未开启” | 点“个人云同步 → 开启个人云同步”；若失败，先恢复网络并重试。 |
| 同步失败 | 恢复网络，重新进入小程序，再点“立即同步”；不要先清缓存或卸载。 |
| 图片无法上传 | 确认 bucket 存在、权限仍为“仅创建者可读写”，并检查平台的照片隐私声明。 |
| 出现付费或升级提示 | 先确认是否为当前环境到期或容量不足；确有需要时按实际套餐续费，不购买与个人使用无关的能力。 |
